# Layer A (Deterministic Stripping) vs Layer B (Statistical Rewriting)

## Executive summary
Layer A and Layer B represent two complementary tiers of text watermark mitigation. Layer A deterministically removes non-printing carrier characters with zero compute overhead, whereas Layer B uses probabilistic model rewriting to disrupt statistical token distribution biases.

## Dimension-by-Dimension Matrix

| Evaluation Criteria | Layer A: Deterministic Stripping | Layer B: Statistical Rewriting | Advantage / Notes |
| :--- | :--- | :--- | :--- |
| **Primary Target** | Invisible Unicode, zero-width chars, bidi tags | Token-frequency biases, green-lists, Gumbel | Different threat models |
| **Compute Overhead** | Negligible (pure CPU regex / codepoint check) | High (requires LLM / RoBERTa inference) | Layer A is instantaneous |
| **Dependencies** | Python standard library only | PyTorch, Hugging Face, or local LLM (Ollama) | Layer A is zero-dependency |
| **Text Semantics** | Exactly 100% preserved (character-level clean) | Slightly perturbed (paraphrased phrasing) | Layer A preserves exact wording |
| **Efficacy on KGW/SynthID** | Ineffective (cannot alter token n-grams) | High (breaks token n-gram correlations) | Layer B required for statistical marks |

## Decision rubric / When to choose which
- **Use Layer A alone when**: You only need to scrub copy-pasted invisible characters, zero-width spaces, or metadata markers.
- **Use Layer B in addition to Layer A when**: The text was generated by a foundation model known to implement statistical token sampling (e.g. Gemini SynthID, open-LLM Kirchenbauer green-lists).

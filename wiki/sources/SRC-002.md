# SRC-002: GitMCP for watermarks-remover

## Metadata & Provenance
- **Service**: GitMCP by Ido Sal ([idosal/git-mcp](https://github.com/idosal/git-mcp))
- **Live Endpoint**: `https://gitmcp.io/guillaumemeyer/watermarks-remover`
- **Protocol**: Model Context Protocol (MCP) via Server-Sent Events (SSE) and HTTP Remote.
- **Related Source**: [[SRC-001]] (The underlying `watermarks-remover` repository).

## Purpose & Main Function
Provide an instant, zero-maintenance Model Context Protocol (MCP) server exposing the live documentation, architecture, and API references of the `guillaumemeyer/watermarks-remover` repository directly to AI programming environments.

## Integration Protocols
- **Cursor**: Configured in `~/.cursor/mcp.json` via HTTP URL.
- **Claude Desktop**: Configured in `claude_desktop_config.json` using `npx mcp-remote`.
- **Windsurf**: Configured in `~/.codeium/windsurf/mcp_config.json` using `serverUrl`.
- **VSCode**: Configured in `.vscode/mcp.json` via SSE.
- **Cline & Highlight AI**: Custom SSE connection directly to the HTTPS endpoint.

## Value in Knowledge Architecture
- Bridges human documentation into machine-queryable context for agentic systems.
- Allows AI coding agents to dynamically query CLI flags, API schemas (`/inspect`, `/clean`, `/detect`), and deployment configurations without manual copy-pasting.

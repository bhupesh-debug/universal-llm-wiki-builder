## Purpose & Main Question
How can authors and content owners strip multi-vendor synthetic AI watermarks and provenance metadata (Claude, Gemini/SynthID, OpenAI, open-LLM greenlists, C2PA, EXIF) from text and media files they legitimately own for privacy, confidentiality, and hygiene?

## Core Architecture & Key Mechanisms

### 1. Multi-Layer Defense Matrix
- **Layer A (Deterministic Text Cleaning)**:
  - Targets invisible Unicode carriers, zero-width spaces (`\u200b`), soft hyphens (`\u00ad`), bidi overrides, exotic whitespace, and Unicode tag characters.
  - Implemented in standard-library Python (`inspect_text.py`, `clean_text.py`) with zero external dependencies.
- **Layer B (Statistical / Token-Sampling Watermark Mitigation)**:
  - Targets statistical token distribution watermarks: Kirchenbauer green-list (KGW), Aaronson keyed-Gumbel (EXP), and SynthID-Text.
  - Mitigated via detection-guided iterative rewriting (`rewrite_text.py`): applies a composite strategy such as `paraphrase@0.8,mlm@0.2` (Masked Language Modeling via RoBERTa + LLM paraphrasing).
  - Evaluators: MarkLLM research harness, Gumbel same-key replay (`detect_gumbel.py`), or bigram-Jaccard lexical divergence.
- **File Metadata & Container Cleaning**:
  - Strips C2PA manifests, EXIF, XMP, and custom metadata chunks from images (PNG, JPEG, WebP, AVIF, HEIC, TIFF, SVG), documents (PDF, DOCX, XLSX, PPTX, EPUB, ODT, HTML, Markdown), and audiovisual containers (MP4, MOV, WAV, MP3, FLAC).
  - Uses `qpdf` for structural PDF rebuilding and `exiftool` / `c2patool` for deep manifest excision.
- **Pixel-Domain Image Watermarks**:
  - Integrates CtrlRegen (ControlNet + DINOv2 IP-Adapter controllable regeneration via `mertizci/noai-watermark`) and reverse-SynthID scoring (`aloshdenny/reverse-SynthID`).

### 2. Client-Server Decoupling
- **Agent Skill**: Thin client written in pure Markdown (`skills/remove-ai-marks/SKILL.md`) that communicates via HTTP calls. Requires no local Python on the agent host.
- **Core HTTP Service**: Python 3.10+ standard library HTTP server (`service/scripts/server.py`) running on `127.0.0.1:8765`.
- **Deterministic Harness Hook**: `PostToolUse` hook running on `Write|Edit|MultiEdit|NotebookEdit` in Claude Code (`hook_written_file.py`) to clean or check files on disk automatically.

## Strengths, Biases, & Limitations
- **Strengths**: Zero runtime dependencies for core text and container stripping; comprehensive file format coverage; rigorous handling of binary files vs text (avoids corruption).
- **Limitations**: Chat response text cannot be modified before user display due to harness limits; Layer B requires LLM backends (Ollama/OpenAI compatible); pixel-domain image restoration requires high GPU VRAM and heavy external models (~10 GB).
